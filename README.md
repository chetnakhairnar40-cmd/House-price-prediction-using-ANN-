# House-price-prediction-using-ANN-# House Price Prediction Using ANN

## Project Overview
This project uses an Artificial Neural Network (ANN) to predict
house prices based on different features using Python and Deep Learning.

The project includes data preprocessing, categorical encoding,
feature scaling, model training, and evaluation.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Jupyter Notebook

## Project Features
- Data exploration and preprocessing
- Handling categorical features using encoding techniques
- Feature scaling using StandardScaler
- Training an ANN regression model
- Predicting house prices
- Model evaluation using MSE, RMSE, MAE, and R² Score

## ANN Model Architecture
- Input Layer: 32 neurons, ReLU activation
- Hidden Layer: 16 neurons, ReLU activation
- Hidden Layer: 8 neurons, ReLU activation
- Output Layer: 1 neuron

## Model Configuration
- Optimizer: Adam
- Loss Function: Mean Squared Error
- Epochs: 200
- Batch Size: 32

## Dataset Features
The dataset includes features such as:
- Condition
- Bedrooms
- Garage
- Location
- Price (Target Variable)

## Project Files
- ANN house price prediction.ipynb - Jupyter Notebook
  containing the implementation.
- House price prediction.csv - Dataset used for training.

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Keep the dataset CSV file in the same folder as the notebook.
4. Open the notebook in Jupyter Notebook.
5. Run the cells to train the ANN model and predict house prices.
